# Microcontrollers Projects

A collection of hands-on embedded systems and microcontroller projects developed for learning, experimentation, and practical application.

The repository focuses on low-level programming, peripheral interfacing, communication protocols, real-time concepts, and hardware debugging using different microcontroller platforms.

## Repository Structure

```text
Microcontrollers/
├── 00-Texas-Instruments/
├── 01-STM32-Projects/
├── 02-Bus-Systems-Projects/
├── .gitignore
└── README.md
```

### 00-Texas-Instruments
Projects and exercises based on Texas Instruments microcontrollers, including bare-metal programming and peripheral-level development.

### 01-STM32-Projects
STM32-based embedded projects developed mainly with STM32CubeIDE and the STM32 HAL.

Current projects include:

- **SSD1306 OLED Driver** – I2C communication with a 128×64 SSD1306 OLED display.
- **UART LED Control** – UART-controlled GPIO and LED behavior using polling and interrupts.
- **Ultrasonic Parking Assistance System** – HC-SR04 distance measurement with OLED feedback and buzzer-based obstacle warning.

### 02-Bus-Systems-Projects
Projects focused on embedded communication buses and networking concepts such as CAN and other serial communication protocols.

## Hardware & Tools

This repository documents my progress in embedded systems through practical projects. Each project is organized separately and may contain its own README with hardware connections, software architecture, implementation details, and usage instructions.
