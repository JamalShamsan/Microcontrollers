# DS18B20 Temperature Sensor – 1-Wire Lab

## Overview

This project investigates the **DS18B20 digital temperature sensor** using an **Arduino Nano** and the **1-Wire communication protocol**.

The sensor temperature is read by the Arduino and transmitted to a PC through USB serial communication. A Python script records the measurements with timestamps and stores them for visualization and analysis.

## Hardware

- Arduino Nano
- DS18B20 temperature sensor
- 5 kΩ pull-up resistor
- Oscilloscope
- Peltier element

## Software

- Arduino 
- Python
- Serial communication
- Data plotting and analysis

## Project Features

- Temperature measurement with DS18B20
- 1-Wire communication
- USB serial data transmission
- Timestamped measurement recording
- Temperature-over-time plotting
- Oscilloscope analysis of the 1-Wire signal
- Thermal response and time-constant analysis


## Result

The experiment successfully demonstrated temperature acquisition, 1-Wire communication analysis, and thermal response measurement. The measured thermal time constant was approximately **170.8 s**.
